# X Films — website redesign preview

Live preview: https://xfilms25.github.io/xfilms-redesign/

- `index.html` — homepage
- `projects/<name>/` — one page per project (generated)
- `projects.json` — all project info: titles, synopses, credits, cast, stills, trailers
- `assets/` — shared styles and scripts for the project pages

To change a project page, edit `projects.json` and run `python3 build.py`.
